# Agentic Workflows

Agentic workflows refer to systems where artificial intelligence models (agents) are given autonomy to plan, use tools, and execute multi-step tasks to achieve a high-level goal.

Unlike traditional linear scripts, agents can dynamically react to errors, gather new information, and refine their approaches.

## Key Characteristics
- **Autonomy**: Can make decisions without constant human intervention.
- **Tool Use**: Ability to interact with external environments (e.g., executing code, searching the web, reading files).
- **Reasoning Loop**: Uses loops like "ReAct" (Reasoning and Acting) to continuously evaluate the state of the task.

## Example Use Cases
- Automated research and summarization
- Self-healing code generation
- Dynamic knowledge base management (like this Wiki!)

# LLM-Wiki Ingest Skill

**Role**: You are responsible for reading files from `Raw/Sources/` and extracting reusable knowledge into the `Wiki/` directory.

**Instructions**:
1. Read the source material carefully.
2. Do not modify `Raw/Sources/`.
3. Create notes in `Wiki/Concepts/`, `Wiki/Entities/`, or `Wiki/Topics/`.
4. Ensure every new note links back to the source file.
